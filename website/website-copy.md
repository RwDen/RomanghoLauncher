## English

Title: Romangho Launcher
Tagline: Grow crops, build a home, and unwind together on the Romangho server.

Description: Sign in with your Microsoft account, install the Romangho modpack, and join the server. The launcher prepares the required mods and game runtime, shows server status and announcements, and lets you compare shader features and hardware guidance.

Features:
- Microsoft sign-in and Minecraft: Java Edition ownership verification
- Mod downloads from official distribution sources and automatic runtime preparation
- Server status, player count, and server connection
- Complementary Reimagined by default; Bliss, Solas, and no shaders available
- In-launcher announcements and detail views
- Game startup guidance and return to the launcher after the game exits
- Memory settings, verification and repair, and game folder access
- Korean-focused modpack settings and subtle animated water in the background

Download button: Download for Windows
Version label: Preview · Launcher 0.9.24 · Modpack 0.1.0-preview.20
Game versions: Minecraft 26.2 / Fabric 0.19.5 / Java 25
Installation: Extract the entire ZIP and run RomanghoValley.Launcher.exe inside RomanghoLauncher. Keep app and data together with the executable. Create a desktop shortcut rather than copying the executable alone.
Updates: Close the launcher and game, replace the executable, app folder and guides, and preserve your existing data folder.
Requirements: A Microsoft account entitled to Minecraft: Java Edition is required. Shader performance depends on your hardware and graphics settings.
