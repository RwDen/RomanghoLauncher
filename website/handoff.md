반영할 핵심 변경:
1. 예전의 전체 ZIP 수동 가져오기 설명을 공식 배포처에서 직접 내려받는 설치 설명으로 변경.
2. 선릿밸리·콘헤이븐 등 이전 이름 대신 ‘로망호 서버 / ROMANGHO SERVER SEASON 2’ 표기.
3. 최신 메인 화면, 셰이더 비교, 공지 상세, 메모리 설정 이미지로 교체.
4. ZIP을 풀면 RomanghoLauncher/app/data가 준비되는 새 배포 구조 안내.
5. 셰이더는 Complementary Reimagined가 기본값이며 Bliss, Solas, None을 선택할 수 있도록 설명. AstraLex와 Photon은 소개하지 않음.
6. 정식 1.0이 아닌 미리보기 버전으로 표시. GitHub의 releases/latest 링크 대신 위의 v0.9.24 고정 다운로드 주소 사용.
7. 다운로드 버튼은 관리자 툴박스가 아닌 일반 사용자용 런처 ZIP만 연결.

주의: 스크린샷의 상태와 공지는 예시입니다. 운영 시간·현재 접속자·상시 온라인을 보장하는 문구를 만들지 마세요. 최소·권장 하드웨어 수치는 별도 측정 전까지 임의로 확정하지 마세요.
