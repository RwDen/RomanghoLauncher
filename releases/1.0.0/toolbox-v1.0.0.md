# 로망호 관리자 툴박스 1.0.0
기존 WPF 관리자 도구를 계승한 Windows x64 배포입니다. 공지 초안·게시·이력, 서버 상태·플레이어·로그 조회, 저장·시작·종료·재시작·관리 명령 기능을 유지합니다.

개발·QA·운영 연결을 분리하고 고정 시험 서버 주소를 제거했습니다. 서버 명령에는 SSH 키 인증, 고정 호스트 지문, 설치된 서버 에이전트의 UID·대상·환경·허용 동작 검사가 필요합니다. 중요 작업 확인 및 감사 기록을 적용합니다. 무인 권한 우회나 QA 초기화 기능은 포함하지 않습니다.

**서버 연결은 설치 안내에 따른 별도 운영자 준비가 필요합니다.** 서버 에이전트·root 소유 정책·검증된 recovery guard를 먼저 설치해야 하며, 기본 예제는 관리자 UID 비어 있음/변경 금지로 닫혀 있습니다. 이번 배포에서 운영 서버를 변경하지 않았습니다. Linux 실제 서비스 연동은 미검증입니다. Python 격리 계약 검사와 실제 WPF DLL의 연결 검증·권한 거부 검사는 통과했습니다.

PuTTY plink/Pageant가 필요합니다. 기존 공지 GitHub 인증은 사용자별 DPAPI로 저장됩니다. 토큰·SSH 개인키는 포함하지 않습니다. 툴박스 업데이트는 독립 ZIP 교체 방식입니다.
