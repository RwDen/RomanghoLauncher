# 로망호 런처 1.0.0
Windows x64 정식 파일 배포입니다. Minecraft 26.2 / Fabric 0.19.5 / Java 25, 모드팩 1.0.0과 사용합니다.

ZIP 전체를 풀고 최상위 RomanghoValley.Launcher.exe를 실행하세요. app 폴더를 함께 보관하세요. 업데이트 시 런처·게임을 종료하고 기존 data 폴더를 보존하세요. Microsoft 계정 및 Minecraft Java 이용 권한이 필요합니다.

서명된 모드팩 revision과 파일 해시를 검증하며 신규 설치에는 Complementary Reimagined와 필수 Typography·GUI 리소스를 적용합니다. 기존 음량·셰이더·사용자 리소스팩은 보존합니다. 런처 자체 업데이트는 ZIP 교체 방식입니다.

파일 공개는 운영 서버 개방을 뜻하지 않습니다. 운영 서버 적용·개방은 별도 점검 후 진행됩니다. Windows 실행 파일의 Authenticode 서명은 제공하지 않습니다. SHA256SUMS.txt로 파일 무결성을 확인하세요.
