# 로망호 모드팩 1.0.0
클라이언트와 서버는 동일한 1.0.0 배포 세트입니다. Minecraft 26.2 / Fabric Loader 0.19.5 / Java 25.

일반 이용자는 런처 1.0.0을 사용하세요. 별도 클라이언트 배포는 Modrinth 형식 .mrpack이며 모드·셰이더를 검증된 원래 배포 URL에서 받습니다. 서버 파일은 Romangho-QoL-26.2-server-1.0.0.zip입니다. 서버 설치는 운영자의 백업·정상 종료 확인 후 진행해야 합니다.

기존 검수 구성의 내부 모드 버전을 보존했습니다: 코어 0.14.25-integrated.qa7.guideflow, 프로필 0.1.2-reassembly.qa1, Naturalist 2.0.7. 신규 기본 셰이더는 Complementary Reimagined이며 QA 무음·시험 계정·월드는 포함하지 않습니다.

아래 개별 JAR 및 overrides는 런처용 배포 자산입니다. 파일 공개는 운영 서버에 적용하거나 서버를 개방했다는 뜻이 아닙니다. 기존 종료 정체 및 Linux 서비스 연동의 잔여 검증은 운영 개방 전 별도로 관리합니다.
