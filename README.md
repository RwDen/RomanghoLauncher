# Romangho Launcher

A Windows desktop launcher for a small private Minecraft: Java Edition server community, with a Korean-language interface.

Romangho Launcher helps players prepare the community's modpack, sign in with their own Microsoft account, and launch the game to join the server.

## Features

- Microsoft account sign-in and Minecraft: Java Edition ownership verification.
- Installation from a complete local modpack ZIP.
- Game environment preparation and launch.
- Automatic minimization to the system tray while the game is running, and restoration when the game closes.

## Development

The launcher is under active development and has been tested locally. Initial use is intended for a small group of friends, approximately one to three players. The project is non-commercial.

CurseForge API integration is planned to download eligible modpack files from official sources while respecting each author's third-party distribution settings. Files unavailable through the API will require downloads from their official project pages and local import.
